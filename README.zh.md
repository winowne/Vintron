# Vintron

## 阶段

这个项目将分为 5 个阶段完成：

1. 了解婴儿大致如何思考，并尝试制作一个模仿 0 个月至 1 岁婴儿的文本模型；
2. 强化结果并强化“眼睛”，让模型能够通过表情符号看见虚拟世界；
3. 模型不再通过表情符号，而是通过机器视觉看见世界，但学习方式仍类似于婴儿；
4. 创建 3D 世界和 3D 物体，同时模型的年龄仍处于 0 个月至 1 岁阶段；
5. 提高模型的年龄并完成项目的全部目标。

所有阶段的详细说明可以在 [stages 文件夹](./stages) 中查看。

## 目标

创建一个实验性模型，使其架构在某些方面比普通语言模型更接近人类学习和感知的原理。

项目的主要目标：

- 研究通过与周围世界互动进行学习，是否能够带来对概念更深入的理解；
- 研究感知、记忆、语言、学习和决策之间的联系；
- 为进一步创建能够感知周围世界并与之互动的智能机器人奠定基础。

## 核心理念

模型将被置于一个虚拟 3D 空间中，这个空间会成为它的周围世界。

模型不会一开始就只通过文本进行训练，而是从感知物体的实际含义开始学习。

例如：

**“狗” → 模型看见一只狗**

这样，模型会逐渐把词语与其他词语、物体、物体的外观以及与物体互动的经验联系起来。

完成初步训练后，模型将被置于一个更复杂的模拟环境中，在那里它会遇到许多物体和动物。

例如，周围世界中同时存在狗和猫。模型必须自主确定：

- 狗在哪里；
- 猫在哪里；
- 它们有什么区别；
- 这些物体分别叫什么。

之后，周围世界的复杂程度会逐步增加。

## 学习顺序

计划从简单的感知逐步发展到更复杂的理解：

1. 感知周围空间。
2. 学习单独的物体。
3. 形成概念。
4. 区分相似的物体。
5. 学习与周围世界互动。
6. 形成并使用记忆。
7. 学习语言。
8. 学习数学。
9. 学习其他知识领域。
10. 过渡到类似学校教育的学习模式。
11. 检验将所学知识应用于新情境的能力。

随着实验的进行，学习顺序和方法也会不断调整。

## 可能的应用

如果这种架构被证明有效，它有望用于创建能力更强的自主机器人。

虚拟环境还可以用于开展一些直接在人类身上进行会成本高、耗时长或存在伦理困难的实验。

例如，可以研究不同的学习方式：

- 更偏数学的学习；
- 更偏人文的学习；
- 不同的学科学习顺序；
- 不同的知识巩固方法；
- 与学习环境互动的不同方式。

这些实验有助于了解哪些学习方法更适合人工系统，部分结果未来也可能为教育技术提供思路。

## 最终目标

在虚拟世界中创建一个实验性智能系统，然后验证是否能够将其架构从模拟环境迁移到实体机器人上。

理想情况下，同一种感知原理应当先适用于虚拟摄像头，之后也适用于机器人的真实摄像头。

**虚拟世界 → 人工智能 → 实体机器人**

项目的目标不是立即创造人类心智，而是逐步验证一些假设：人工智能的学习是否可以更加接近人类感知、记忆和获取经验的原理。
