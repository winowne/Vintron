# Vintron

## Stages

This project will be developed in 5 stages:

1. Understanding approximately how an infant's brain works and attempting to create a text model that imitates an infant from 0 months to 1 year old.
2. Reinforcing the results and adding "eyes" so that the model can see the virtual world through emojis.
3. The model will see the world through machine vision rather than emojis, while its learning will remain similar to that of an infant.
4. Creating a 3D world and 3D objects while keeping the model at an age of 0 months to 1 year.
5. Increasing the model's age and achieving all project goals.

A detailed description of all stages can be found in the [stages folder](./stages).

## Goal

To create an experimental model whose architecture is, in some respects, closer to the principles of human learning and perception than a conventional language model.

The main goals of the project are:

- to investigate whether learning through interaction with the surrounding world can lead to a deeper understanding of concepts;
- to study the connection between perception, memory, language, learning, and decision-making;
- to create a foundation for the future development of an intelligent robot capable of perceiving and interacting with the world around it.

## Core Idea

The model is placed in a virtual 3D space that becomes its surrounding world.

Instead of initially training the model only on text, learning begins with perceiving the real meaning of objects.

For example:

**“dog” → the model sees a dog**

In this way, the model gradually connects a word not only with other words, but also with an object, its appearance, and the experience of interacting with it.

After initial training, the model is placed in a more complex simulation where it encounters many objects and animals.

For example, the surrounding world contains dogs and cats. The model must independently determine:

- where the dog is;
- where the cat is;
- how they differ;
- what these objects are called.

The complexity of the surrounding world then gradually increases.

## Learning Sequence

The plan is to move from simple perception toward more complex understanding:

1. Perceiving the surrounding space.
2. Learning about individual objects.
3. Forming concepts.
4. Distinguishing similar objects.
5. Learning to interact with the surrounding world.
6. Forming and using memory.
7. Learning language.
8. Learning mathematics.
9. Learning other areas of knowledge.
10. Transitioning to a learning model resembling school education.
11. Testing the ability to apply acquired knowledge in new situations.

The order and methods of learning will change as experiments are conducted.

## Possible Applications

If this architecture proves effective, it could potentially be used to create more capable autonomous robots.

The virtual environment also makes it possible to conduct experiments that would be expensive, time-consuming, or ethically difficult to conduct directly on people.

For example, different approaches to learning can be studied:

- more mathematically oriented learning;
- more humanities-oriented learning;
- different sequences for studying subjects;
- different methods for reinforcing knowledge;
- different ways of interacting with the learning environment.

Such experiments may help determine which learning methods are better suited to artificial systems. Some results could also provide ideas for educational technologies in the future.

## Ultimate Goal

To create an experimental intelligent system in a virtual world and then investigate whether its architecture can be transferred from simulation to a physical robot.

Ideally, the same perception principle should work first with a virtual camera and then with a real robot camera.

**Virtual world → artificial intelligence → physical robot**

The project does not aim to immediately create a human mind. Its purpose is to gradually test individual hypotheses about how artificial intelligence learning can be brought closer to the principles of human perception, memory, and experience.
