# 阶段 1 —— 实验性的类婴儿文本模型

## 概述

第一阶段是 Vintron 项目的实验性起点。本阶段旨在研究：一个简单的文本模型是否能够以某些方面类似于婴儿早期发展的方式进行学习。

本阶段具有探索性质。项目正在验证一些不仅对 Vintron、也对整个人工智能社区而言具有新颖性的想法。模型并不试图复制人类婴儿或人类意识，而是一个用于研究学习、发展和互动的简化模型。

## 主要目标

主要目标是创建一个能够持续学习的模型，而不是只完成一次固定的训练过程。

模型应当能够：

- 从少量由自然赋予婴儿、类似本能的基础声音或符号开始；
- 随着时间推移学习识别和使用新的声音；
- 逐步扩展内部词汇或字母表，之后将声音组合成音节和短词；
- 保存之前学习到的有用信息；
- 随着模拟年龄增加而改变自身能力；
- 通过文本或其他简单的符号输入和输出进行互动。

模拟的发展阶段覆盖从出生到一岁的时期。

## 发展模型

模型的发展将被划分为大致的阶段：

1. **新生儿阶段** —— 使用最少量的声音和基础内部状态初始化模型。
2. **早期学习** —— 识别重复模式，并区分熟悉的声音和新声音。
3. **声音获取** —— 将新的声音或符号加入模型可用的字母表。
4. **建立联系** —— 将声音与反复出现的上下文、动作或反应联系起来。
5. **记忆与强化** —— 保留有用的模式，并通过反复互动加强这些模式。
6. **第一年结束** —— 评估模型的词汇、记忆和反应的发展情况。

这些阶段是当前的工作假设。随着实验产生新的结果，其结构和实现方式可能会发生变化。

## 学习原则

第一阶段关注以下原则：

- **持续学习：** 模型在创建后仍然可以继续学习。
- **有限的初始知识：** 模型从刻意限制的少量声音或符号开始。
- **渐进式成长：** 模型逐步获得新元素，而不是一开始就获得完整字母表。
- **重复与强化：** 重复的经验可以加强已经学习到的联系。
- **随时间发展：** 模拟年龄可以影响模型的状态、能力和学习策略。
- **实验驱动的设计：** 根据实验观察结果调整架构和规则。

## 计划中的实验

最初的实验可以研究：

1. 模型如何保存和识别基础声音；
2. 新声音如何加入字母表；
3. 重复输入是否能够改善识别或反应质量；
4. 模型如何区分熟悉的输入和陌生的输入；
5. 模拟年龄增加时记忆如何变化；
6. 模型是否能够在新的上下文中使用已经学会的声音。

## 局限性

本阶段是一个简化的计算实验，并不声称能够模拟婴儿大脑的生物学机制。与婴儿发展的类比只是用于提出关于学习、记忆和逐步获得能力的组织方式的假设。

## 预期结果

在第一阶段结束时，项目应当拥有一个可工作的文本原型。该原型能够持续学习少量符号词汇、保存已经学习的信息，并在从出生到一岁的不同模拟年龄下接受评估。
